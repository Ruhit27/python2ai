A structured training plan that says what to do in each session and how it changes over time: which exercises, how many [sets](./Set.md) and [reps](./Rep.md), what weights or effort ([RPE](./RPE.md)), which days, and how to add [progressive overload](./Progressive%20overload.md). Also called a *routine* or *plan*.

The advantage of a program over "doing whatever feels right" is consistency. Progress comes from doing similar work repeatedly and slowly making it harder — which only works if you know what you did last time. Well-known beginner programs are simple: a few [compound exercises](./Compound%20exercise.md), two or three [full-body workouts](./Full-body%20workout.md) a week, and small weight jumps each session.

A program is built around a [split](./Split.md) (how the week is divided), a [frequency](./Training%20frequency.md), and a plan for progress. Longer programs often include [periodization](./Periodization.md) and scheduled [deloads](./Deload.md). The best program is one you can follow consistently.

_Avoid:_ "workout" for a whole program — a workout is one session; a program is the plan across weeks.

_Usage:_

"What's the best program?"

"The one you'll actually stick to. For a beginner, three full-body days with the big lifts is hard to beat."
