description: Planning training in phases that change over time — like volume blocks, then heavier strength blocks — instead of doing the same thing forever.
---

Organizing training into planned phases, each with a different focus, so progress continues over months and years. It's how long-term [programs](./Program.md) manage [progressive overload](./Progressive%20overload.md) once simple week-to-week progress stops.

Common styles:

| Style | How it works |
| --- | --- |
| Linear | Weight goes up and reps go down steadily over weeks |
| Undulating | Heavy, medium, and light days rotate within each week |
| Block | Weeks of high volume, then weeks of heavy strength work, then a peak |

Each phase (often called a *block* or *mesocycle*) usually lasts 3–8 weeks and often ends with a [deload](./Deload.md). Switching focus — say, from higher-[volume](./Volume.md) muscle-building to heavier [strength](./Strength.md) work — can help break a [plateau](./Plateau.md).

Beginners don't need much periodization; adding a little weight each session works for months. It becomes more useful as progress slows.

_Avoid:_ "periodization" for random program-hopping — it's a planned sequence, not frequent switching.

_Usage:_

"I've been stuck for months on the same 3×10."

"Time for some periodization. Try a four-week heavier block of 5×5, then return to 3×10."
